## Description
This project focuses on ai smart glasses for blind. It aims to provide a robust, efficient, and scalable solution using modern technologies and best practices in the field.

## Key Features
- High performance architecture
- Extensible and modular design
- Comprehensive data processing capabilities
- Easy-to-use interface and quick setup

## Tech Stack
- YOLOv8\n- scikit-fuzzy\n- Raspberry Pi\n- GPS\n- TTS

## Quick Start
```bash
git clone https://github.com/iMuneebK/VISION-SmartGlasses-FYP.git
cd VISION-SmartGlasses-FYP
pip install -r requirements.txt
python main.py
```
